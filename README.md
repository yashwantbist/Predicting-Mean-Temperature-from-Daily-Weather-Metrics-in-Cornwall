# Predicting-Mean-Temperature-from-Daily-Weather-Metrics-in-Cornwall
This project leverages machine learning techniques to predict the **mean daily temperature** in **Cornwall, Ontario**, using various weather metrics. It's a practical example of using regression models to analyze and forecast environmental data.
![image](https://github.com/user-attachments/assets/9b42049f-98f5-4053-aa83-be360de7db41)

---

 Project Objective

To build a predictive model that accurately estimates the **mean temperature** based on daily recorded weather features such as:
- Max/Min Temperature
- Humidity
- Wind Speed
- Precipitation
- Atmospheric Pressure
- and more

---

 Techniques Used

- **Data Preprocessing**  
  - Handling missing values  
  - Feature encoding  
  - Feature scaling  

- **Modeling**  
  - Random Forest Regressor  
  - Linear Regression  
  - Model Evaluation using R² Score
